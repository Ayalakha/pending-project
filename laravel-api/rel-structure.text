User
├── companies (hasMany Company)
├── blogs (hasMany Blog)  
└── comments (hasMany Comment)

Company
├── owner (belongsTo User)
└── servicesOrProducts (hasMany ServiceOrProduct)

Blog
├── author (belongsTo User)
└── comments (hasMany Comment)

Comment
├── author (belongsTo User)
└── blog (belongsTo Blog)

ServiceOrProduct
└── company (belongsTo Company)
